# Particle Path Plugin — Paper 1.20.1

Paper adaptation of Particle Path Mod.

- Minecraft 1.20.1
- Paper 1.20.x
- Java 17
- Install the generated JAR in `plugins/`.

Commands:
`/particlepath create <name> <particle>`
`/particlepath modify <name> <particle>`
`/particlepath show <name>`
`/particlepath hide <name>`
`/particlepath remove <name>`
`/particlepath list`

Use a normal stick to select A with left-click and B/C/D... with right-click.
